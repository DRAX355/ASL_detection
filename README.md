# ASL Detection

This project implements an American Sign Language (ASL) alphabet detection system using machine learning and computer vision. It is designed to recognize static ASL alphabet gestures (A–Z) from images using a trained model.

## 📁 Dataset

The model is trained using the **ASL Alphabet Dataset** available on Kaggle:

🔗 [ASL Alphabet Dataset on Kaggle](https://www.kaggle.com/datasets/grassknoted/asl-alphabet)

This dataset contains images of ASL letters (A–Z) captured under various lighting and background conditions.

## 🚀 Features

- ASL alphabet classification using image input
- Model trained with Scikit-learn
- User-friendly notebook (`asldetection.ipynb`)
- Supports integration with real-time webcam input (optional future extension)

## 🛠️ Requirements

- Python 3.x
- NumPy
- OpenCV (`cv2`)
- scikit-learn
- pickle
